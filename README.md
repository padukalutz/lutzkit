##LutzKit
CLI toolkit untuk membuat dan mengelola project.

##Features
- Interactive project generator
- HTML/CSS/JS templates
- React + Vite
- Next.js
- Express
- Node.js
- Go Basic / CLI / API
- Project detection
- Dependency install
- Dependency cleanup
- Environment doctor
- Embedded templates

##Commands

lutzkit new
lutzkit init
lutzkit list
lutzkit search <query>
lutzkit doctor
lutzkit install
lutzkit uninstall
lutzkit update
